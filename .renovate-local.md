# Renovate merge guidance

Read by the local Renovate merge skill. The public renovate-eval action and
skill do not read this file.

## What changes what runs

"How Other Repositories Use This One" in `.renovate-eval.md` lists what other
repositories use at `@main`. An update to any of it changes what they run the
moment it merges: deploy and check it after merging, as below. Every other
update only needs CI.

## Deploying, after merging

Nothing to do: merging to `main` is the deploy.

## Checking it works

Run something in another repository that uses the changed part, through the
merged code. For the Renovate evaluation, start a dry run that evaluates one
open Renovate PR in a repository that has a `.renovate-local.md`, without
posting anything:

```bash
gh workflow run renovate-eval.yaml -R claytono/REPO --ref main -f pr_number=PR -f dry_run=true
```

The run must succeed, and the evaluation must actually have run. The review
action skips it when Claude usage is over its limit and the job still shows
success. It uploads the `renovate-eval-PR` artifact only when the evaluation
ran, so check for it:

```bash
gh api repos/claytono/REPO/actions/runs/RUN/artifacts --jq '.artifacts[].name'
```

It must list `renovate-eval-PR`. If the run succeeded without it, the check is
unverified: report it and do not retry. A pass with nothing to evaluate skips
the whole job and does not count either. Each check uses Claude subscription
usage for one evaluation.
